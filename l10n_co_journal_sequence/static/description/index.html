Secuencias de Diarios para Colombia

📋 Descripción

Este módulo proporciona un sistema completo de secuencias personalizadas para diarios contables en Odoo, específicamente diseñado para la localización colombiana. Permite configurar numeración automática para entradas contables y notas de crédito.

🚀 Características

  • Secuencias de Entradas: Configuración de secuencias automáticas para asientos contables
  • Secuencias de Notas de Crédito: Numeración separada para documentos de reversión
  • Numeración Editable: Control manual del siguiente número de secuencia
  • Integración con Diarios: Asociación directa con diarios contables
  • Validación Automática: Verificación de resolución DIAN y configuración
  • Compatibilidad Total: Reemplazo transparente de journal_sequence
  • Interfaz de Usuario: Pestaña dedicada en la configuración de diarios
  • Localización Colombiana: Adaptado a requisitos fiscales colombianos

🏗️ Ecosistema y Dependencias

Este módulo forma parte del ecosistema completo de localización colombiana para Odoo:

Dependencias requeridas:
  • base - Módulo base de Odoo
  • account - Contabilidad

Módulos que dependen de este:

  • l10n_co_catalog - Catálogo de datos maestros DIAN
  • l10n_co_edi_electronic_invoice - Facturación electrónica DIAN (obtenlo en FacturaLatam)

Módulos complementarios del ecosistema:

  • l10n_co - Localización base de Colombia
  • l10n_co_global_discount - Gestión de descuentos
  • l10n_co_layout_custom - Plantillas PDF profesionales
  • l10n_co_import_electronic_invoice - Importación XML facturas
