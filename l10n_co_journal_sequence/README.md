# Secuencias de Diario Colombiano

Este módulo proporciona una gestión simplificada de secuencias para entradas de diario en la localización de Colombia para Odoo 17.

## Características

- Campos de secuencia estándar para entradas y notas de crédito
- Gestión automática del número siguiente
- Integración directa con diarios contables
- Configuración simplificada para necesidades básicas de numeración

## Instalación

1. Instale el módulo desde Odoo Apps o copie los archivos al directorio de addons.
2. Actualice la lista de módulos en Odoo.
3. Instale el módulo `l10n_co_journal_sequence`.

## Configuración

Después de instalar el módulo:

1. Vaya a Contabilidad > Diarios.
2. Seleccione un diario.
3. En la pestaña "Secuencias", configure las secuencias para entradas y notas de crédito.

## Uso

El módulo automáticamente gestiona la numeración de asientos contables basándose en las secuencias configuradas en cada diario.
