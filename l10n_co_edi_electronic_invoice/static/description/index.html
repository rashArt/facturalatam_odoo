📋 Descripción

Módulo profesional para facturación electrónica en Colombia con integración completa a la DIAN. Solución certificada que permite a las empresas colombianas generar, firmar y transmitir documentos electrónicos de manera automática según la resolución 000042 de 2020 de la DIAN.

🚀 Características

  • Generación Automática: Facturas electrónicas según normativa DIAN
  • Firma Digital: Envío automático a API certificada para firma
  • Transmisión DIAN: Envío directo y obtención automática de CUFE
  • Documentos Completos: Facturas, notas crédito y débito
  • POS Integrado: Facturación electrónica en tiempo real
  • Reportes: Trazabilidad completa de documentos
  • Configuración Automática: Según resolución DIAN de la empresa
  • Manejo de Contingencias: Gestión de reenvío

🏗️ Ecosistema y Dependencias

Módulo comercial central del ecosistema de localización colombiana para Odoo:

Dependencias requeridas:
  • account - Contabilidad
  • l10n_co_catalog - Catálogos maestros Colombia
  • account_debit_note - Notas débito
  • sale_management - Gestión de ventas
  • l10n_co_global_discount - Descuentos globales
  • point_of_sale - Punto de venta

Módulos complementarios del ecosistema:

  • l10n_co_catalog - Catálogos maestros DIAN
  • l10n_co_global_discount - Gestión de descuentos
  • l10n_co_layout_custom - Plantillas PDF profesionales
  • l10n_co_import_electronic_invoice - Importación XML facturas
