📋 Descripción

Módulo complementario que proporciona plantillas PDF personalizadas y profesionales para documentos de facturación electrónica en Colombia. Diseñado específicamente para cumplir con los requisitos de representación impresa establecidos por la DIAN según resolución.

🚀 Características

  • Plantillas Profesionales: Diseño elegante y moderno adaptado a normativa DIAN
  • Documentos Completos: Facturas, notas crédito y débito, documentos POS
  • Código QR: Tamaño y posición óptimos para escaneo
  • CUFE/CUDE Visible: Destacado y fácil de identificar
  • Branding Empresarial: Logo y colores corporativos personalizables

🏗️ Ecosistema y Dependencias

Módulo complementario del ecosistema de localización colombiana para Odoo:

Dependencias requeridas:
  • l10n_co_catalog - Catálogos maestros Colombia
  • l10n_co_edi_electronic_invoice - Facturación electrónica DIAN (obtenlo en FacturaLatam)

Módulos complementarios del ecosistema:

  • l10n_co_catalog - Catálogos maestros DIAN
  • l10n_co_edi_electronic_invoice - Facturación electrónica DIAN (obtenlo en FacturaLatam)
  • l10n_co_global_discount - Gestión de descuentos
  • l10n_co_import_electronic_invoice - Importación XML facturas
