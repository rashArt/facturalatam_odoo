📋 Descripción

Módulo complementario que permite aplicar descuentos globales en órdenes de venta y facturas, adaptado específicamente para la localización colombiana. Optimizado para trabajar en conjunto con el ecosistema de facturación electrónica DIAN.

🚀 Características

  • Descuentos por Porcentaje: Aplicar porcentaje sobre el subtotal
  • Descuentos por Valor Fijo: Valor específico independiente del total
  • Órdenes de Venta: Descuentos antes de confirmar la orden
  • Facturas de Cliente: Descuentos en facturación directa
  • Facturas de Proveedor: Manejo de descuentos recibidos
  • Notas de Crédito: Ajustes y correcciones
  • Cálculo Automático: Recálculo de impuestos según normativa colombiana
  • Integración DIAN: Compatible con facturación electrónica

🏗️ Ecosistema y Dependencias

Módulo complementario del ecosistema de localización colombiana para Odoo:

Dependencias requeridas:
  • sale - Ventas
  • sale_management - Gestión de ventas
  • account - Contabilidad
  • l10n_co_catalog - Catálogos maestros Colombia

Módulos complementarios del ecosistema:

  • l10n_co_catalog - Catálogos maestros DIAN
  • l10n_co_edi_electronic_invoice - Facturación electrónica DIAN
  • l10n_co_layout_custom - Plantillas PDF profesionales
  • l10n_co_import_electronic_invoice - Importación XML facturas
