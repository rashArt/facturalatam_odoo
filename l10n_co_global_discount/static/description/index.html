📖 Cómo Usar

1

Configurar

Ir a Configuración → Ajustes → Ventas y activar "Descuentos Globales Colombia"

2

Crear Orden

Crear orden de venta o factura normalmente con productos y servicios

3

Aplicar Descuento

Seleccionar tipo de descuento (% o fijo), ingresar cantidad y hacer clic en "Aplicar"

4

Automático

El sistema recalcula impuestos automáticamente y crea línea de descuento
