📋 Descripción

Este módulo proporciona catálogos de datos maestros necesarios para la localización de Colombia, incluyendo tipos de documentos, tipos de organizaciones, tipos de régimen, y más. Es esencial para implementar correctamente la facturación electrónica y el cumplimiento normativo colombiano en Odoo.

🚀 Características

  • Catálogos Maestros DIAN: Tipos de documentos, identificación, formas de pago
  • División Territorial: Departamentos y municipios de Colombia
  • Tipos de Organización: Persona natural, jurídica, régimen fiscal
  • Integración Contable: Configuración de impuestos y diarios
  • Recursos Humanos: Configuración de nómina y contratos
  • Productos: Unidades de medida según estándares colombianos
  • Facturación Electrónica: Plantillas y establecimientos
  • Importación CSV: Actualización masiva de datos

🏗️ Ecosistema y Dependencias

Este módulo forma parte del ecosistema completo de localización colombiana para Odoo:

Dependencias requeridas:
  • base - Módulo base de Odoo
  • l10n_co - Localización base de Colombia
  • account - Contabilidad
  • update_from_csv - Actualización desde CSV
  • l10n_co_journal_sequence - Secuencias de diarios
  • hr_payroll_community - Nómina comunitaria
  • hr_payroll_account_community - Contabilización de nómina

Módulos complementarios del ecosistema:

  • l10n_co_edi_electronic_invoice - Facturación electrónica DIAN (obtenlo en FacturaLatam)
  • l10n_co_global_discount - Gestión de descuentos
  • l10n_co_layout_custom - Plantillas PDF profesionales
  • l10n_co_import_electronic_invoice - Importación XML facturas
