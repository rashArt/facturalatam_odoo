📋 Descripción

Este módulo proporciona catálogos de datos maestros necesarios para la localización de Colombia, incluyendo tipos de documentos, tipos de organizaciones, tipos de régimen, y más. Es esencial para implementar correctamente la facturación electrónica y el cumplimiento normativo colombiano en Odoo.

🎯 ¿Por qué elegir este módulo?

Cumplimiento total con la normativa DIAN, datos actualizados y configuración automática para facturación electrónica en Colombia.

📥 Instalación y Configuración

🔧 Requisitos del Sistema

Versión Odoo: 18.0+
Localización: l10n_co
Módulos Base: account, hr_payroll
Licencia: AGPL-3

📋 Pasos de Instalación

  1. Descargar e instalar el módulo desde Odoo Apps
  2. Activar el modo desarrollador en Odoo
  3. Ir a Aplicaciones → Buscar "Catálogo de Datos para Colombia"
  4. Hacer clic en "Instalar" y esperar la configuración automática
  5. Configurar los parámetros específicos de su empresa

⚙️ Configuración Post-Instalación

  • Configuración → Localización Colombiana: Establecer parámetros básicos de la empresa
  • Contabilidad → Diarios: Verificar secuencias automáticas
  • Contabilidad → Impuestos: Revisar configuración de impuestos colombianos
  • EDI → Establecimientos: Configurar establecimientos para facturación electrónica
