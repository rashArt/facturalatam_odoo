Importar Facturas Electrónicas Colombia

Licencia: LGPL-3 | Versión: 18.0.1.0.1 | Autor: Ricardo Colonia

📋 Descripción

Módulo que permite importar archivos XML de facturas electrónicas colombianas para crear automáticamente proveedores, productos y órdenes de compra. Simplifica el proceso de registro de facturas de proveedores colombianos mediante la importación directa de archivos XML con formato DIAN.

🚀 Características

  • Importación XML: Carga archivos XML de facturas electrónicas DIAN
  • Creación de Proveedores: Automática con información completa del XML
  • Creación de Productos: Con especificaciones detalladas y precios
  • Órdenes de Compra: Generación automática con líneas de pedido
  • Transferencia CUFE: Automática a facturas de proveedor
  • Mapeo de Unidades: Unidades de medida DIAN automáticas
  • Soporte ZIP: Importación de archivos comprimidos
  • Integración Completa: Con módulo de compras de Odoo

🏗️ Ecosistema y Dependencias

Módulo complementario del ecosistema de localización colombiana para Odoo:

Dependencias requeridas:
  • base - Módulo base de Odoo
  • purchase - Módulo de compras
  • account - Contabilidad
  • l10n_co_catalog - Catálogos maestros Colombia

Módulos complementarios del ecosistema:

  • l10n_co_catalog - Catálogos maestros DIAN
  • l10n_co_edi_electronic_invoice - Facturación electrónica DIAN (obtenlo en FacturaLatam)
  • l10n_co_global_discount - Gestión de descuentos
  • l10n_co_layout_custom - Plantillas PDF profesionales

📋 Cómo Usar el Módulo

1

Ir a Compras

Navega a Compras → Órdenes de compra en tu instalación de Odoo

2

Crear/Abrir Orden

Crea una nueva orden de compra o abre una existente en estado borrador

3

Importar Factura

Haz clic en el botón "Importar Factura" disponible en la orden

4

Seleccionar Archivo

Elige el archivo XML o ZIP de la factura electrónica desde tu computador

5

Procesar Automáticamente

El sistema procesa automáticamente y crea todos los registros necesarios

6

¡Listo!

Proveedor, productos y líneas de compra creados automáticamente

🎯 ¿Qué hace automáticamente el sistema?

✓ Crea/actualiza el proveedor con datos del XML
✓ Establece la referencia del proveedor con número de factura y CUFE
✓ Guarda el CUFE para transferirlo a futuras facturas
✓ Crea las líneas de productos con precios y cantidades
✓ Crea productos nuevos si no existen en el sistema

📄 Estructura XML Soportada

El módulo procesa automáticamente los siguientes elementos del XML de factura electrónica:

🏢 Información del Proveedor

<cac:AccountingSupplierParty> <cac:Party> <cac:PartyName> <cbc:Name>Nombre del proveedor</cbc:Name> </cac:PartyName> <cac:PhysicalLocation> <cac:Address> <cbc:ID>codigo del municipio</cbc:ID> <cbc:CityName>Nombre del municipio</cbc:CityName> <cac:AddressLine> <cbc:Line>Direccion</cbc:Line> </cac:AddressLine> </cac:Address> </cac:PhysicalLocation> <cac:Contact> <cbc:Telephone>telefono</cbc:Telephone> <cbc:ElectronicMail>correo@email.com</cbc:ElectronicMail> </cac:Contact> </cac:Party> </cac:AccountingSupplierParty>

📋 Información de la Factura

<cbc:ID>numero de la factura</cbc:ID> <cbc:UUID schemeID="1" schemeName="CUFE-SHA384"> numero del CUFE </cbc:UUID>

📦 Líneas de Productos

<cac:InvoiceLine> <cbc:ID>numero de la linea</cbc:ID> <cbc:Description>nombre del producto</cbc:Description> <cbc:BrandName>marca</cbc:BrandName> <cbc:ModelName>modelo</cbc:ModelName> <cac:Item> <cac:StandardItemIdentification> <cbc:ID schemeID="999">referencia</cbc:ID> </cac:StandardItemIdentification> </cac:Item> <cac:Price> <cbc:PriceAmount currencyID="COP">valor</cbc:PriceAmount> <cbc:BaseQuantity unitCode="NIU">cantidad</cbc:BaseQuantity> </cac:Price> </cac:InvoiceLine>

📏 Mapeo de Unidades de Medida

NIU: Unidades
KGM: Kilogramos
LTR: Litros
MTR: Metros
MTK: Metros²
MTQ: Metros³
HUR: Horas
DAY: Días
TNE: Toneladas
GRM: Gramos
